Amar Clothing POS (Root)
├── metadata.json                 <- প্রজেক্ট পরিচিতি ও এআই সেটিংস
├── build.gradle.kts             <- প্রজেক্ট লেভেল গ্র্যাডল কনফিগারেশন
├── app/
│   ├── build.gradle.kts         <- অ্যাপ লেভেল লাইব্রেরি ও ডিপেনডেন্সি কনফিগ
│   └── src/
│       └── main/
│           ├── AndroidManifest.xml   <- অ্যাপ্লিকেশনের পারমিশন ও অ্যাক্টিভিটি ঘোষণা
│           ├── res/
│           │   └── values/
│           │       └── strings.xml   <- অ্যাপের বাংলা ও ইংরেজি স্ট্যাটিক টেক্সটসমূহ
│           └── java/com/example/
│               ├── MainActivity.kt   <- অ্যাপটির প্রধান এন্ট্রি পয়েন্ট
│               │
│               ├── data/ (ডাটাবেজ ও মডেল লেয়ার - Room Integration)
│               │   ├── AppDatabase.kt     <- লোকাল Room SQLite ডাটাবেজ সেটআপ
│               │   ├── PosRepository.kt   <- ভিউমডেলের জন্য ডাটা রিপোজিটরি
│               │   ├── Product.kt         <- পণ্য/ইনভেনটরি টেবিল স্কিমা
│               │   ├── ProductDao.kt      <- প্রোডাক্ট কোয়েরি (ইনসার্ট, ডিলিট, আপডেট)
│               │   ├── SaleRecord.kt      <- ট্রানজেকশন/বিক্রয় রেকর্ড টেবিল স্কিমা
│               │   ├── SaleRecordDao.kt   <- বিক্রয় রিপোর্টের ডাটাবেজ কোয়েরি
│               │   ├── ShopProfile.kt     <- দোকানের তথ্যাদি সংরক্ষণের স্কিমা
│               │   └── ShopProfileDao.kt  <- দোকানের প্রোফাইল সম্পর্কিত কোয়েরি
│               │
│               └── ui/ (ইউজার ইন্টারফেস লেয়ার - Jetpack Compose)
│                   ├── LanguageHelper.kt  <- বাংলা-ইংরেজি বাটন ও ইন্টারফেস ল্যাঙ্গুয়েজ লোডার
│                   ├── PosApp.kt          <- প্রধান থিম, ইন্টারফেস, ওনার এবং সেলসম্যান ড্যাশবোর্ড স্ক্রিন
│                   ├── PosViewModel.kt    <- অ্যাপের বিজনেস লজিক, স্টেট ও ক্যালকুলেশন হ্যান্ডলার
│                   └── theme/
│                       ├── Theme.kt       <- মেটেরিয়াল ডিজাইন ৩ (Dynamic Color) কাস্টম থিমিং
│                       ├── Type.kt        <- অ্যাপের টাইপোগ্রাফি (ফন্ট সেটিংস)
│                       └── Color.kt       <- POS থিমের আধুনিক কালার প্যালেট
